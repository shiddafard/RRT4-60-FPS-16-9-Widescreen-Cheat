# RR-T4 60FPS-16:9 and Ultrawide Aspect Ratio Cheat #
# Now with 21:9 and 32:9 ultrawide support!

A port of the cheat originally for the JP version converted to work with US copies (SLUS-00797)

# All credit should go to AEONG_AEONG on the GBAtemp forums for creating this patch in the first place. Without his work, this wouldn't be happening. #

Using Deepseek 4.1 Flash (via T3 Code) a conversion of JP only cheat code was able to work on the USA copy (SLUS-00797) This US converted cheat has full parity with the JP cheat at the time of publishing. (10-28-2026)


NOTE: When using PGXP, have depth buffer set to OFF. Having it on causes Z-fighting with textures (I learned this the hard way).

Original thread showcasing the cheat on the JP version: https://gbatemp.net/threads/i-created-60-fps-widescreen-cheat-codes-for-ridge-racer-type-4.684958/
